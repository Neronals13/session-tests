# Тести до сесії

Сайт для підготовки до сесії: тести з предметів УКД у режимах тренування та іспиту.

Предмети: Математичний аналіз, Комп’ютерна дискретна математика, Теорія ймовірностей, Інженерія програмного забезпечення.

Прогрес зберігається в браузері (localStorage), тож в кожного користувача він свій.
